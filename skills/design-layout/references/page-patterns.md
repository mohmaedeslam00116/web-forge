# Page structure patterns

These patterns are reference arrangements for common tasks. Treat them as starting points, not industry templates. Reorder, combine, simplify, or replace them based on the actual content.

## Persuade surfaces

Useful ingredients: promise, audience fit, proof, explanation, demonstration, comparison, objections, pricing/terms, and next action. Not every page needs every ingredient. The first viewport must explain why the visitor should continue, but it does not always need a centered hero or two buttons.

## Operate surfaces

Useful ingredients: global navigation, workspace context, key task entry, filters, primary data view, status and feedback, history, help, and recovery. Prioritize task flow and scanning over marketing sections. Density should match the user's expertise and task frequency.

## Read surfaces

Useful ingredients: title and metadata, summary, table of contents, article body, annotations, data tables, citations, related reading, and next/previous navigation. Use only what supports comprehension.

## Experience surfaces

Useful ingredients: artifact-first presentation, collection index, contextual labels, details, exploration controls, transitions, and contact or acquisition paths. Preserve orientation and do not sacrifice accessibility for immersion.

## Content-shape patterns

- **A sequence:** onboarding, procedure, timeline, curriculum, event schedule.
- **A comparison:** prices, plans, alternatives, before/after, specifications.
- **A collection:** portfolio, products, archive, media library.
- **A record:** account details, inventory row, case file, appointment, transaction.
- **A narrative:** case study, product story, editorial feature, mission explanation.
- **A spatial relationship:** map, floor plan, network, route, hierarchy.
- **A control surface:** filters, parameters, editor, dashboard, configuration.

Choose the pattern that matches the information. Avoid turning every item into a rounded card. Tables, indexes, plain text, rows, diagrams, lists, and open layouts are often clearer.

## Section pacing

Vary visual intensity only when the content role changes. A quiet section after an intense one can improve focus; several quiet sections can be correct for a reading page or tool. Do not alternate colors or layouts merely to create motion down the page.
