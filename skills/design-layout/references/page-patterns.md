# Content-first composition worksheet

This reference is a diagnostic tool, not a gallery of copyable page templates. Do not select a pattern by industry label. Discover the dominant information relationship first.

## Identify the dominant relationship

- **Sequence:** order matters; users follow, review, or resume a progression.
- **Comparison:** values or alternatives must be aligned to reveal differences.
- **Collection:** users locate, filter, browse, and choose among items.
- **Record:** one entity has attributes, history, status, and permitted actions.
- **Narrative:** meaning unfolds through a deliberate reading sequence.
- **Spatial system:** proximity, position, route, or topology changes the decision.
- **Live operations:** status changes continuously and exceptions require action.
- **Creation surface:** a user makes or edits an artifact while consulting supporting context.
- **Mixed:** one dominant relationship plus supporting relationships.

## Page rhythm

Change visual treatment when content roles change, not to alternate section backgrounds mechanically. A dense sequence can be correct; a calm editorial flow can be correct. Use hierarchy and grouping to establish rhythm before decoration.

## Responsive composition

For each target size, state whether the screen changes its navigation, hierarchy, grouping, controls, or content order. Do not rely on a single grid simply changing column count.
