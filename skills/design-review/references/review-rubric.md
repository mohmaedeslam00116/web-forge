# Review rubric

Use this as a prompt for evidence-based review, not a universal score target.

| Dimension | What to inspect | Evidence that supports a strong result |
|---|---|---|
| Task clarity | Is the primary job apparent and achievable? | A user can identify and complete the main path without guessing |
| Hierarchy | What is seen and understood first? | Visual weight follows task importance, not a repeated component recipe |
| Direction fidelity | Does the result express the selected direction? | Type, composition, media, color, and interaction support the Design Passport |
| Content readability | Can real content be scanned or read comfortably? | Appropriate measure, line-height, labels, and content density |
| Composition | Does structure fit the content? | Useful grouping, clear edges, no unnecessary card grids or arbitrary asymmetry |
| Craft | Are states, alignment, and details resolved? | Controls behave consistently; no clipping, layout shifts, or meaningless decoration |
| Product specificity | Does the interface fit this product and audience? | Content and key patterns could not be swapped into an unrelated product unchanged |
| Accessibility | Can people with relevant access needs use it? | Semantics, keyboard, focus, contrast, labels, and motion behavior are verified |
| Responsiveness | Does it adapt to real device widths? | Key tasks remain usable without accidental overflow or hidden actions |

Do not optimize the originality score independently of task clarity, platform conventions, or user expectations.
