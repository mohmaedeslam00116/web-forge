# Visual World Catalog

This catalog is a vocabulary for art direction. It is not a list of templates and must never be applied by industry label alone. A project may combine compatible families, but each combination must have a product reason.

| Family | Visual grammar | Useful materials/media | Risks to avoid |
|---|---|---|---|
| Editorial / magazine | Masthead, columns, folios, pull quotes, captions, feature hierarchy, deliberate long-form pacing | Photography, illustrations, diagrams, data stories, annotations | Turning every page into a newspaper; using type as the only visual asset |
| Cinematic / immersive | Full-bleed frames, layered scenes, dramatic scale, controlled overlays, scroll or transition choreography | Film stills, video, 3D scenes, atmospheric photography, sound where appropriate | Heavy motion, unreadable overlays, video as decoration |
| Photographic / product showcase | Subject-led art direction, intentional crop, macro/detail, large image fields, comparison views | Original product photos, lifestyle shots, device renders, cutaways | Generic stock photos, inconsistent lighting, random image grids |
| Illustration-led | Bespoke visual metaphor, characters, scenes, explanatory drawings, strong shape language | Vector illustration, hand-drawn art, isometric diagrams, editorial spot art | Generic blob illustrations and unrelated mascots |
| 3D / spatial | Volume, light, camera, object manipulation, spatial depth, interactive exploration | 3D model, WebGL/WebGPU, rendered object, product configurator | Expensive effects with no task value; inaccessible canvas-only content |
| Brutalist / raw digital | Exposed structure, hard edges, strong blocks, uncompromising hierarchy, deliberately raw material | Large type, grids, raw image, mono accents, high-contrast fields | Mistaking unfinished work for intentional rawness |
| Neo-brutalist / playful | Bold border, confident shadow, bright fields, tactile buttons, graphic stamps | Illustration, sticker forms, cutouts, colored panels | Applying the same thick border to every component |
| Maximalist / collage | Layered media, dense composition, juxtaposition, overlap, expressive typography | Cutout photography, scans, paper, texture, collage, type artifacts | Visual noise, inaccessible overlap, random decoration |
| Luxury / hospitality | Controlled space, tactile materials, atmospheric images, precise details, high craft | Architecture, product macro, fabric, interiors, cinematic imagery | Assuming luxury means empty white space and tiny gray text |
| Swiss / international grid | Strong alignment, modular grid, precise hierarchy, typographic and image rhythm | Photography, diagrams, numbered structures, information graphics | Turning grid discipline into thin-line minimalism by default |
| Retro / analog | Era-specific artifacts, print behavior, color reproduction, texture, type and interface references | Grain, halftone, pixel art, CRT, paper, stamps, cassette/disc forms | Fake nostalgia with generic filters; historical inaccuracy |
| Data / scientific | Data hierarchy, chart families, scales, uncertainty, labels, dense but legible information | Charts, maps, schematics, plots, technical illustration | Decorative dashboards, fake metrics, color-only encoding |
| Map / spatial / network | Spatial relationship is the primary story; map + list, topology, paths, graph or layers | Maps, nodes, routes, floor plans, diagrams, GIS layers | A decorative map with no operational meaning |
| Community / social | People and user-generated media, conversational hierarchy, identity, activity and moderation states | Avatars, photos, video, reactions, feeds, threaded content | Fake people/content, engagement bait, confusing trust signals |
| Marketplace / catalog | Discovery, filtering, comparison, product detail, editorial merchandising | Product imagery, category art, comparison tables, reviews and specs | Equal-card grids for all inventory; fabricated reviews or ratings |
| Education / learning | Learning path, examples, practice, feedback, progression, explanatory visuals | Diagrams, illustrations, video, interactive exercises, notes | Gamification that distracts from learning |
| Creative canvas / editor | The artifact dominates; tools stay contextual; layers, direct manipulation, inspector and timeline | Canvas, media, 3D, waveform, layer previews, tool affordances | Treating every editor like a generic dashboard |
| Entertainment / music / video | Artwork and playback are central; discovery and emotion shape the interface | Album/cover art, posters, video, audio waveforms, motion | Hiding controls, autoplay sound, replacing content with decorative animation |
| Civic / service / government | Clear trust, tasks, eligibility, forms, status, guidance and recovery | Maps, diagrams, document previews, identity/help cues | Marketing-first hero structures on essential service tasks |
| Food / travel / local discovery | Place, appetite, route, atmosphere, provenance, useful details | Food/venue photography, map, itinerary, cards where meaningful | Generic destinations and stock photography that misrepresents a place |
| Fashion / culture / campaign | Art-directed imagery, editorial pacing, seasonal visual identity, expressive type | Lookbooks, campaign photography, video, collage, runway stills | Repeating one e-commerce product grid as the whole experience |

## Diagnostic questions

1. What is the dominant artifact: text, product, person, place, data, image collection, spatial model, or creation canvas?
2. What should the visitor feel: confidence, appetite, urgency, wonder, focus, delight, authority, calm, or discovery?
3. Where does the visual proof come from: real product capture, photography, illustration, data, a demonstration, or a physical metaphor?
4. Does the visual world have a material and lighting logic, or is it only a color palette?
5. Would the concept still be recognizable with its copy removed and its palette desaturated?
6. Is restrained minimalism truly appropriate, or is it simply the model's safest learned default?
